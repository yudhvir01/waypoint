# Manuals (Writebook-ready)

Every file in this folder is a chapter, written in [Writebook](https://github.com/basecamp/writebook)'s
own page format: YAML front matter with a `title`, then the page body in Markdown.
Filenames are numbered so the reading order matches file order.

When you deploy a Writebook instance, create a book (e.g. "Waypoint") and paste each
file's body in as a page with that file's `title`. Nothing here depends on Writebook
being deployed yet — these are plain Markdown and readable on their own in the
meantime.

| `02-connecting-your-supabase-project.md` | Connecting Your Supabase Project |

| `10-on-your-phone.md` | On Your Phone |

| `12-words-and-writing.md` | Words and Writing |

Every chapter opens with a `## TL;DR` list, which the app shows as a box at the
top, followed by the detail.
